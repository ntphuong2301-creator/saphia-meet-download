# Saphia Meet — tải phần mềm

Ứng dụng ghi âm, chép lời và vẽ sơ đồ cuộc họp của **Saphia Group** (Windows 10/11).

## Tải bản mới nhất

- **Máy chưa cài:** [Tải trình cài (tự tải bản mới nhất, ~126 MB)](https://github.com/ntphuong2301-creator/saphia-meet-download/raw/main/SaphiaMeet-CaiDat.exe)
- **Máy đã cài bản cũ:** [Tải bản cập nhật nhỏ (~6 MB)](https://github.com/ntphuong2301-creator/saphia-meet-download/raw/main/SaphiaMeet-CapNhat.exe)

Hai link trên luôn trỏ về bản mới nhất. Trình cài cần Internet trong lúc cài.

Phiên bản hiện tại: xem file `latest.txt`.

## Cài đặt

1. Bấm đúp file vừa tải.
2. Nếu Windows hiện "Windows protected your PC": bấm **More info / Thêm thông tin** → **Run anyway / Vẫn chạy**.
3. Bấm **Tiếp** → **Cài đặt**. Không cần quyền quản trị. Cài đè lên bản cũ vẫn giữ nguyên dữ liệu và các cuộc họp đã lưu.
4. Lần đầu mở app: làm theo 4 bước hướng dẫn và đăng nhập **tài khoản Claude của chính bạn**.

Cần hỗ trợ: liên hệ bạn phụ trách kỹ thuật của công ty.
